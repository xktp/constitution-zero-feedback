# Constitution Zero — Português (Brasil)

[Todos os idiomas](../../README.md#languages)

Canal público de feedback do Constitution Zero. A pessoa responsável pelo projeto recebe relatos aqui e por e-mail.

Escolha um formulário e escreva no idioma de sua preferência. É necessário ter uma conta no GitHub para abrir uma issue. Se não puder usar o GitHub ou se o formulário não for acessível, envie um e-mail. Capturas de tela são opcionais; uma descrição em texto é suficiente.

## Formulários

- [Relatar um problema](https://github.com/xktp/constitution-zero-feedback/issues/new?template=pt-BR-bug.yml)
- [Corrigir conteúdo ou citação](https://github.com/xktp/constitution-zero-feedback/issues/new?template=pt-BR-correction.yml)
- [Acessibilidade ou tradução](https://github.com/xktp/constitution-zero-feedback/issues/new?template=pt-BR-accessibility-translation.yml)
- [Sugerir uma funcionalidade](https://github.com/xktp/constitution-zero-feedback/issues/new?template=pt-BR-feature.yml)

## Feedback privado / alternativa por e-mail

As issues e os anexos são públicos. Não inclua senhas, tokens, dados pessoais ou informações confidenciais. Envie vulnerabilidades de segurança e relatos privados por e-mail.

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## Escopo e tratamento

Este repositório contém orientações e modelos de feedback. O código da aplicação permanece em um repositório privado separado. Receber um relato não significa aprovação, revisão independente ou compromisso de implementar mudanças. Não há prazo de resposta garantido.
