# Constitution Zero — Français

[Toutes les langues](../../README.md#languages)

Retours publics sur Constitution Zero. La personne responsable du projet reçoit les signalements ici et par e-mail.

Choisissez un formulaire et écrivez dans la langue de votre choix. Un compte GitHub est nécessaire pour ouvrir un ticket. Si vous ne pouvez pas utiliser GitHub ou si le formulaire est inaccessible, contactez-nous par e-mail. Les captures sont facultatives ; une description textuelle suffit.

## Formulaires

- [Signaler un problème](https://github.com/xktp/constitution-zero-feedback/issues/new?template=fr-bug.yml)
- [Corriger un contenu ou une citation](https://github.com/xktp/constitution-zero-feedback/issues/new?template=fr-correction.yml)
- [Accessibilité ou traduction](https://github.com/xktp/constitution-zero-feedback/issues/new?template=fr-accessibility-translation.yml)
- [Proposer une fonctionnalité](https://github.com/xktp/constitution-zero-feedback/issues/new?template=fr-feature.yml)

## Retours privés / contact par e-mail

Les tickets et les pièces jointes sont publics. Ne publiez pas de mots de passe, de jetons, de données personnelles ou confidentielles. Signalez les vulnérabilités et envoyez les retours privés par e-mail.

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## Périmètre et traitement

Ce dépôt contient les consignes et les modèles de retour. Le code de l’application reste dans un dépôt privé distinct. Recevoir un signalement ne vaut ni approbation, ni validation indépendante, ni engagement à effectuer une modification. Aucun délai de réponse n’est garanti.
