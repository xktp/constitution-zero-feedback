# Constitution Zero — हिन्दी

[सभी भाषाएँ](../../README.md#languages)

Constitution Zero के लिए सार्वजनिक प्रतिक्रिया का स्थान। परियोजना के ज़िम्मेदार व्यक्ति यहाँ और ईमेल से रिपोर्ट प्राप्त करते हैं।

नीचे कोई फ़ॉर्म चुनें और अपनी पसंद की भाषा में लिखें। Issue भेजने के लिए GitHub खाते की ज़रूरत होती है। यदि आप GitHub इस्तेमाल नहीं कर सकते या फ़ॉर्म इस्तेमाल करने में बाधा है, तो ईमेल भेजें। स्क्रीनशॉट वैकल्पिक हैं; लिखित विवरण पर्याप्त है।

## प्रतिक्रिया फ़ॉर्म

- [समस्या की रिपोर्ट](https://github.com/xktp/constitution-zero-feedback/issues/new?template=hi-bug.yml)
- [सामग्री या उद्धरण में सुधार](https://github.com/xktp/constitution-zero-feedback/issues/new?template=hi-correction.yml)
- [सुगम्यता या अनुवाद](https://github.com/xktp/constitution-zero-feedback/issues/new?template=hi-accessibility-translation.yml)
- [सुविधा का सुझाव](https://github.com/xktp/constitution-zero-feedback/issues/new?template=hi-feature.yml)

## निजी प्रतिक्रिया / ईमेल का विकल्प

Issue और संलग्न फ़ाइलें सार्वजनिक होती हैं। पासवर्ड, टोकन, व्यक्तिगत या गोपनीय जानकारी शामिल न करें। सुरक्षा संबंधी कमज़ोरियाँ और निजी प्रतिक्रिया ईमेल से भेजें।

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## दायरा और प्रक्रिया

इस रिपॉज़िटरी में प्रतिक्रिया के निर्देश और फ़ॉर्म हैं। एप्लिकेशन का स्रोत कोड एक अलग निजी रिपॉज़िटरी में रहता है। रिपोर्ट मिलना सहमति, स्वतंत्र समीक्षा पूरी होने या बदलाव लागू करने का वादा नहीं है। उत्तर के लिए कोई निश्चित समय सीमा नहीं है।
