# Constitution Zero — 한국어

[모든 언어](../../README.md#languages)

Constitution Zero 공개 의견 접수 창구입니다. 프로젝트 책임자가 이 저장소와 이메일로 제보를 받습니다.

아래 양식을 선택하고 편한 언어로 작성해 주세요. Issue를 제출하려면 GitHub 계정이 필요합니다. GitHub를 사용할 수 없거나 양식에 접근하기 어려우면 이메일을 이용해 주세요. 스크린샷은 선택 사항이며 글로만 설명해도 됩니다.

## 의견 제출 양식

- [문제 신고](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ko-bug.yml)
- [내용 또는 인용 수정](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ko-correction.yml)
- [접근성 또는 번역](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ko-accessibility-translation.yml)
- [기능 제안](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ko-feature.yml)

## 비공개 의견 / 이메일 창구

Issue와 첨부 파일은 공개됩니다. 비밀번호, 토큰, 개인정보 또는 기밀 자료를 포함하지 마세요. 보안 취약점과 비공개 의견은 이메일로 보내 주세요.

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## 범위 및 처리 안내

이 저장소에는 의견 제출 안내와 양식만 있습니다. 애플리케이션 소스 코드는 별도의 비공개 저장소에서 관리합니다. 제보 접수는 동의, 독립 검토 완료 또는 변경 구현 약속을 뜻하지 않습니다. 답변 기한은 보장하지 않습니다.
