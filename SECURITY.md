# Private and security reports

**Email: [support@constitutionzero.com](mailto:support@constitutionzero.com)**

Please use email for suspected vulnerabilities, exposed credentials, personal information, private tenant data or other confidential feedback. Do not open a public issue containing those details. If unsure whether a report is safe to publish, begin by email.

Include a brief description, the affected public page/component and version if known, and a minimal redacted reproduction. Do not send passwords, live tokens, database dumps or other people's private data. Do not probe accounts or systems without authorization. Further details can be coordinated privately with the project owner.

The project owner is the receiving contact. There is no guaranteed response deadline, bounty, encrypted mailbox claim or assertion of verified email delivery. A configured email address alone is not proof that a report has been received.

For instructions in your language, see the [language guides](README.md#languages). For non-sensitive feedback, use the [public forms](README.md#languages).
