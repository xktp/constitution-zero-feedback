# Constitution Zero — 日本語

[すべての言語](../../README.md#languages)

Constitution Zero の公開フィードバック窓口です。プロジェクト責任者が、このリポジトリとメールで報告を受け付けます。

下のフォームを選び、使い慣れた言語で記入してください。Issue の投稿には GitHub アカウントが必要です。GitHub を利用できない場合やフォームを操作しにくい場合は、メールをご利用ください。スクリーンショットは任意で、文章だけでも構いません。

## フィードバックフォーム

- [不具合の報告](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ja-bug.yml)
- [内容・引用の訂正](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ja-correction.yml)
- [アクセシビリティ・翻訳](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ja-accessibility-translation.yml)
- [機能の提案](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ja-feature.yml)

## 非公開の相談／メール窓口

Issue と添付ファイルは公開されます。パスワード、トークン、個人情報、機密情報を記載しないでください。セキュリティ上の脆弱性や非公開の相談はメールでお送りください。

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## 対象範囲と対応について

このリポジトリにはフィードバックの案内とテンプレートを置いています。アプリケーションのソースコードは別の非公開リポジトリで管理しています。報告の受理は、賛同、独立した審査の完了、変更の実施を意味しません。返信期限は保証しません。
