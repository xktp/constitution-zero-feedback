# Constitution Zero — English

[All languages](../../README.md#languages)

Public feedback for Constitution Zero. The project owner receives reports here and by email.

Choose a form below. You may write in your preferred language. A GitHub account is needed to submit an issue; if you cannot use GitHub or a form is inaccessible, email us. Screenshots are optional; a text description is sufficient.

## Feedback forms

- [Bug report](https://github.com/xktp/constitution-zero-feedback/issues/new?template=en-bug.yml)
- [Content or citation correction](https://github.com/xktp/constitution-zero-feedback/issues/new?template=en-correction.yml)
- [Accessibility or translation](https://github.com/xktp/constitution-zero-feedback/issues/new?template=en-accessibility-translation.yml)
- [Feature suggestion](https://github.com/xktp/constitution-zero-feedback/issues/new?template=en-feature.yml)

## Private feedback / email alternative

Issues and attachments are public. Do not include passwords, tokens, personal information or confidential data. Send security vulnerabilities and private feedback by email instead.

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## Scope and handling

This repository contains feedback instructions and templates. Application source remains in the separate private repository. A report is not an endorsement, independent review or commitment to implement a change. There is no guaranteed response time.
