## ملاحظات خاصة / بديل عبر البريد الإلكتروني

البلاغات والمرفقات علنية. لا تنشر كلمات المرور أو رموز الوصول أو البيانات الشخصية أو السرية. أرسل الثغرات الأمنية والملاحظات الخاصة عبر البريد الإلكتروني.

[support@constitutionzero.com](mailto:support@constitutionzero.com)

يحتوي هذا المستودع على إرشادات الملاحظات ونماذجها. تبقى الشفرة المصدرية للتطبيق في مستودع خاص منفصل. استلام البلاغ لا يعني الموافقة أو اجتياز مراجعة مستقلة أو الالتزام بتنفيذ تعديل. لا نضمن مهلة محددة للرد.
