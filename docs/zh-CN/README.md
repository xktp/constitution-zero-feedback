# Constitution Zero — 简体中文

[全部语言](../../README.md#languages)

Constitution Zero 公开反馈入口。项目负责人负责接收这里的反馈及邮件。

请选择下方表单，可用你习惯的语言填写。提交 Issue 需要 GitHub 账号；无法使用 GitHub 或表单不便操作时，可以发邮件。截图不是必需的，文字描述即可。

## 反馈表单

- [问题报告](https://github.com/xktp/constitution-zero-feedback/issues/new?template=zh-CN-bug.yml)
- [内容或引用更正](https://github.com/xktp/constitution-zero-feedback/issues/new?template=zh-CN-correction.yml)
- [无障碍或翻译反馈](https://github.com/xktp/constitution-zero-feedback/issues/new?template=zh-CN-accessibility-translation.yml)
- [功能建议](https://github.com/xktp/constitution-zero-feedback/issues/new?template=zh-CN-feature.yml)

## 私密反馈／邮箱替代入口

Issue 和附件会公开显示。请勿填写密码、令牌、个人信息或保密资料。安全漏洞和私密反馈请改用邮箱。

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## 范围与处理说明

本仓库仅存放反馈说明和模板，应用源码保留在独立的私有仓库。接收反馈不代表认可、独立审查通过或承诺实施修改，不承诺固定回复时限。
