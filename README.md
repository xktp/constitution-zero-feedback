# Constitution Zero Feedback

Public feedback for Constitution Zero

Choose your language below to report a problem, request a correction, describe an accessibility or translation issue, or suggest a feature. Reports are received by the project owner.

English is listed first; other languages are sorted by language code. Each row uses that language and links to four localized forms and a guide. Use the direct links below to avoid searching through the full template chooser. You may write in any language; translation accuracy and multilingual response times are not independently verified or guaranteed.

## Public or private feedback

Issues and attachments are public. Do not post credentials, personal data, confidential records or undisclosed vulnerabilities. For private feedback, security reports, or an alternative to GitHub, email [support@constitutionzero.com](mailto:support@constitutionzero.com). Screenshots are optional; text is welcome. See [private reporting guidance](SECURITY.md).

## Scope

This repository contains feedback instructions and templates. The application source stays in a separate private repository. Publishing these materials does not open-source the application or grant a license to its code. No blanket license is assigned to reports submitted by others. Opening or closing an issue does not certify research, establish independent review, or authorize real-world actions.

See [contribution and handling guidance](CONTRIBUTING.md). A report is not a commitment to implement a change, and no fixed response time is promised.
