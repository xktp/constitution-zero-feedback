# Constitution Zero — Italiano

[Tutte le lingue](../../README.md#languages)

Feedback pubblico per Constitution Zero. La persona responsabile del progetto riceve le segnalazioni qui e via email.

Scegli un modulo e scrivi nella lingua che preferisci. Per aprire una issue serve un account GitHub. Se non puoi usare GitHub o il modulo non è accessibile, invia un’email. Gli screenshot sono facoltativi: basta una descrizione testuale.

## Moduli di feedback

- [Segnalare un problema](https://github.com/xktp/constitution-zero-feedback/issues/new?template=it-bug.yml)
- [Correggere contenuti o citazioni](https://github.com/xktp/constitution-zero-feedback/issues/new?template=it-correction.yml)
- [Accessibilità o traduzione](https://github.com/xktp/constitution-zero-feedback/issues/new?template=it-accessibility-translation.yml)
- [Proporre una funzionalità](https://github.com/xktp/constitution-zero-feedback/issues/new?template=it-feature.yml)

## Feedback privato / alternativa via email

Le issue e gli allegati sono pubblici. Non includere password, token, dati personali o informazioni riservate. Invia vulnerabilità di sicurezza e segnalazioni private via email.

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## Ambito e gestione

Questo repository contiene istruzioni e modelli per il feedback. Il codice dell’applicazione resta in un repository privato separato. Ricevere una segnalazione non implica approvazione, verifica indipendente o impegno a implementare modifiche. Non è garantito un tempo di risposta.
