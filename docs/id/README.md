# Constitution Zero — Bahasa Indonesia

[Semua bahasa](../../README.md#languages)

Tempat umpan balik publik untuk Constitution Zero. Penanggung jawab proyek menerima laporan di sini dan melalui email.

Pilih formulir di bawah dan tulis dalam bahasa yang Anda inginkan. Akun GitHub diperlukan untuk mengirim issue. Jika Anda tidak dapat menggunakan GitHub atau formulir sulit diakses, kirim email. Tangkapan layar bersifat opsional; penjelasan tertulis sudah cukup.

## Formulir umpan balik

- [Laporkan masalah](https://github.com/xktp/constitution-zero-feedback/issues/new?template=id-bug.yml)
- [Koreksi konten atau kutipan](https://github.com/xktp/constitution-zero-feedback/issues/new?template=id-correction.yml)
- [Aksesibilitas atau terjemahan](https://github.com/xktp/constitution-zero-feedback/issues/new?template=id-accessibility-translation.yml)
- [Saran fitur](https://github.com/xktp/constitution-zero-feedback/issues/new?template=id-feature.yml)

## Umpan balik pribadi / alternatif email

Issue dan lampiran bersifat publik. Jangan sertakan kata sandi, token, data pribadi, atau informasi rahasia. Kirim kerentanan keamanan dan umpan balik pribadi melalui email.

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## Cakupan dan penanganan

Repositori ini berisi panduan dan templat umpan balik. Kode sumber aplikasi tetap berada di repositori privat yang terpisah. Penerimaan laporan bukan persetujuan, hasil tinjauan independen, atau janji untuk menerapkan perubahan. Tidak ada jaminan waktu tanggapan.
