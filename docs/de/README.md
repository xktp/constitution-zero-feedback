# Constitution Zero — Deutsch

[Alle Sprachen](../../README.md#languages)

Öffentliche Rückmeldungen zu Constitution Zero. Die projektverantwortliche Person erhält Meldungen hier und per E-Mail.

Wähle ein Formular und schreibe in deiner bevorzugten Sprache. Zum Erstellen eines Issues brauchst du ein GitHub-Konto. Wenn du GitHub nicht nutzen kannst oder das Formular nicht zugänglich ist, sende eine E-Mail. Screenshots sind freiwillig; eine Textbeschreibung genügt.

## Formulare

- [Fehler melden](https://github.com/xktp/constitution-zero-feedback/issues/new?template=de-bug.yml)
- [Inhalt oder Quellenangabe korrigieren](https://github.com/xktp/constitution-zero-feedback/issues/new?template=de-correction.yml)
- [Barrierefreiheit oder Übersetzung](https://github.com/xktp/constitution-zero-feedback/issues/new?template=de-accessibility-translation.yml)
- [Funktion vorschlagen](https://github.com/xktp/constitution-zero-feedback/issues/new?template=de-feature.yml)

## Vertrauliche Rückmeldung / E-Mail-Alternative

Issues und Anhänge sind öffentlich. Veröffentliche keine Passwörter, Tokens, personenbezogenen oder vertraulichen Daten. Melde Sicherheitslücken und vertrauliche Anliegen per E-Mail.

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## Umfang und Bearbeitung

Dieses Repository enthält Hinweise und Vorlagen für Rückmeldungen. Der Anwendungscode bleibt in einem separaten privaten Repository. Der Eingang einer Meldung bedeutet weder Zustimmung noch unabhängige Prüfung oder eine Zusage zur Umsetzung. Eine Antwortfrist wird nicht garantiert.
