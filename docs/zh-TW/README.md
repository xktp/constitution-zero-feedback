# Constitution Zero — 繁體中文

[全部語言](../../README.md#languages)

Constitution Zero 公開回饋入口。專案負責人負責接收這裡的回饋及電子郵件。

請選擇下方表單，可使用你習慣的語言填寫。提交 Issue 需要 GitHub 帳號；無法使用 GitHub 或表單不便操作時，可以寄信。截圖並非必要，文字描述即可。

## 回饋表單

- [問題回報](https://github.com/xktp/constitution-zero-feedback/issues/new?template=zh-TW-bug.yml)
- [內容或引用更正](https://github.com/xktp/constitution-zero-feedback/issues/new?template=zh-TW-correction.yml)
- [無障礙或翻譯回饋](https://github.com/xktp/constitution-zero-feedback/issues/new?template=zh-TW-accessibility-translation.yml)
- [功能建議](https://github.com/xktp/constitution-zero-feedback/issues/new?template=zh-TW-feature.yml)

## 私密回饋／電子郵件替代入口

Issue 和附件會公開顯示。請勿填寫密碼、權杖、個人資訊或機密資料。安全漏洞和私密回饋請改用電子郵件。

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## 範圍與處理說明

本儲存庫僅存放回饋說明與範本，應用程式原始碼保留在獨立的私人儲存庫。接收回饋不代表認可、獨立審查通過或承諾實施修改，不承諾固定回覆時限。
