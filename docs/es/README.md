# Constitution Zero — Español

[Todos los idiomas](../../README.md#languages)

Comentarios públicos sobre Constitution Zero. La persona responsable del proyecto recibe los informes aquí y por correo electrónico.

Elige un formulario y escribe en el idioma que prefieras. Necesitas una cuenta de GitHub para enviar una incidencia; si no puedes usar GitHub o el formulario no es accesible, escríbenos por correo. Las capturas son opcionales: basta con una descripción en texto.

## Formularios

- [Informar de un error](https://github.com/xktp/constitution-zero-feedback/issues/new?template=es-bug.yml)
- [Corregir contenido o citas](https://github.com/xktp/constitution-zero-feedback/issues/new?template=es-correction.yml)
- [Accesibilidad o traducción](https://github.com/xktp/constitution-zero-feedback/issues/new?template=es-accessibility-translation.yml)
- [Sugerir una función](https://github.com/xktp/constitution-zero-feedback/issues/new?template=es-feature.yml)

## Comentarios privados / alternativa por correo

Las incidencias y los archivos adjuntos son públicos. No incluyas contraseñas, tokens, datos personales ni información confidencial. Envía las vulnerabilidades y los comentarios privados por correo electrónico.

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## Alcance y gestión

Este repositorio contiene instrucciones y plantillas para comentarios. El código de la aplicación permanece en un repositorio privado separado. Recibir un informe no implica aprobación, revisión independiente ni compromiso de implementar cambios. No se garantiza un plazo de respuesta.
