# Constitution Zero — Русский

[Все языки](../../README.md#languages)

Публичная обратная связь по Constitution Zero. Ответственный за проект получает сообщения здесь и по электронной почте.

Выберите форму ниже и пишите на удобном вам языке. Для создания задачи нужна учётная запись GitHub. Если GitHub или форма недоступны, напишите по электронной почте. Скриншоты необязательны: достаточно текстового описания.

## Формы обратной связи

- [Сообщить об ошибке](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ru-bug.yml)
- [Исправить текст или ссылку](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ru-correction.yml)
- [Доступность или перевод](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ru-accessibility-translation.yml)
- [Предложить функцию](https://github.com/xktp/constitution-zero-feedback/issues/new?template=ru-feature.yml)

## Частное обращение / электронная почта

Задачи и вложения видны всем. Не публикуйте пароли, токены, персональные или конфиденциальные данные. Об уязвимостях и частных вопросах сообщайте по электронной почте.

[support@constitutionzero.com](mailto:support@constitutionzero.com)

## Область применения и обработка

Этот репозиторий содержит инструкции и формы обратной связи. Исходный код приложения остаётся в отдельном закрытом репозитории. Получение сообщения не означает одобрения, независимой проверки или обязательства внести изменения. Срок ответа не гарантируется.
